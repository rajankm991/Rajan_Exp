🔗 Load from OneDrive (paste a share link, saved only in this browser)

In OneDrive: right-click the file → Share → set to "Anyone with the link" (view access is enough) → Copy link → paste it here. The link is stored only in this browser's local storage. This works best with personal OneDrive; some organisation/SharePoint links block this kind of direct browser fetch (CORS) — if that happens, download the file and use Load Excel Workbook instead.

⚙️ GitHub Auto-Sync (one-time setup, saved only in this browser)

Create a token at github.com → Settings → Developer settings → Fine-grained tokens, scoped to just this one repo with Contents: Read & write permission. It's stored only in this browser's local storage and sent directly to GitHub's API — never through us. Once saved, loading an Excel file will show a 🚀 Push to GitHub button that commits data.json for you — no manual download/upload needed.
